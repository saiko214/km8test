# C# ООП тест — дайындық

148+ сұрақтан тұратын тест сайты (қазақ тілінде). Үш режим: барлық сұрақ, бөліктер бойынша (3 бөлік), кездейсоқ 50 сұрақ. Тест соңында нәтиже, пайыз және қателер талдауы көрсетіледі.

## GitHub Pages арқылы жариялау

1. github.com сайтында жаңа репозиторий жасаңыз (мысалы, `test-prep`), **Public** таңдаңыз.
2. **Add file → Upload files** батырмасын басып, осы папкадағы 4 файлды жүктеңіз: `index.html`, `style.css`, `script.js`, `questions.js`. **Commit changes** басыңыз.
3. **Settings → Pages** бөліміне өтіңіз.
4. **Source**: *Deploy from a branch* таңдаңыз. **Branch**: `main`, папка `/ (root)` таңдап, **Save** басыңыз.
5. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://<GitHub-атыңыз>.github.io/test-prep/`

## Жергілікті ашу

`index.html` файлын браузерде ашыңыз (немесе VS Code-та Live Server қолданыңыз).

## Сұрақтарды өзгерту

Барлық сұрақ `questions.js` ішінде. `a` — дұрыс жауаптың нөмірі (0=A, 1=B, 2=C, 3=D, 4=E).
